# Accepted Decisions

This directory contains focused, accepted, durable product or architecture
decisions. These records are authority only for their stated scope and must
still be checked against production compatibility and active code.

Rules:

- Evidence maps remain in `docs/agent-context/`; they describe current code and
  may be reconciled as evidence changes.
- Drafts and proposals do not belong here.
- A decision enters this directory only after it is explicitly accepted.
- An accepted decision states its status and scope.
- When a decision changes materially, add its replacement and mark the old
  record `SUPERSEDED`; do not silently rewrite decision history.
- Current priorities belong in `../11-current-work.md`; completed outcomes
  belong in `../12-completed-work.md`.
